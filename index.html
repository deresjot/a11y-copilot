01

Die Wirklichkeit

Barrieren sind Eigenschaften eines Produkts.

Wenn eine Aufgabe nur mit Maus, gutem Sehvermögen, hoher Konzentration oder perfekter Feinmotorik gelingt, liegt das Problem nicht beim Menschen. Das Produkt stellt eine unnötige Bedingung. Gute Accessibility-Arbeit findet diese Bedingungen, bevor sie Menschen von einer Aufgabe ausschließen.

  • sehenZoom, Kontrast, Blendung, Screenreader
  • hörenUntertitel, Transkript, visuelle Signale
  • bedienenTastatur, Touch, Sprache, Schalter
  • verstehenklare Sprache, Struktur, Rückmeldung
  • konzentrierenweniger Ablenkung, genug Zeit, Fehlertoleranz
  • wechselnkleiner Bildschirm, laute Umgebung, nur eine freie Hand

Accessibility ist Produktqualität. Sie wird entworfen, gebaut und nachgewiesen.

02

03

So wird es benutzt

Erst Kontext laden. Dann die Aufgabe stellen.

Ein KI-Assistent kennt dein Produkt nicht und erinnert sich nicht zuverlässig an jede fachliche Feinheit. Gib ihm deshalb zuerst die Hilfsdatei und danach den konkreten Nutzungspfad, Code oder Entwurf. Die Anleitung führt dich Schritt für Schritt durch diesen Ablauf.

Step-by-step-Anleitung öffnen

  1. Datei mitgeben

    Die Hilfsdatei in den KI-Chat deiner Wahl kopieren oder dort als Datei anhängen.

  2. Konkret fragen

    Aufgabe, betroffenen Ablauf, Code und bekannte Rahmenbedingungen nennen. Eine konkrete Frage liefert eine überprüfbare Antwort.

  3. Quelle und Test verlangen

    Normative Aussagen belegen lassen. Die vorgeschlagene Lösung anschließend im echten Produkt manuell und technisch prüfen.

04

Was eine Datei nicht leisten kann

Gute Antworten sind noch kein Nachweis.

a11y-copilot kann eine Analyse schärfen und schlechte Abkürzungen sichtbar machen. Ob eine Lösung trägt, zeigt sich erst im vollständigen Ablauf, mit realen Browsern, assistiven Technologien und Menschen.

Ein Toollauf ist kein Audit. Eine Stichprobe ist kein Beleg für ungeprüfte Seiten. Und eine plausible Antwort ist keine normative Quelle.

Konformität braucht einen definierten Scope, reproduzierbare Evidenz und manuelle Prüfung. Rechtliche Einordnung und Tests mit Menschen bleiben eigene Aufgaben.
